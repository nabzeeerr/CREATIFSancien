# CREATIFS

Projet PHP de gestion de projets créatifs réalisé dans le cadre des cours.

L'application permet de consulter les projets, d'afficher leurs détails et de gérer les projets avec les fonctionnalités d'ajout, de modification et de suppression.

## Technologies utilisées

- PHP
- MySQL
- HTML / CSS

## Installation

- Importer la base de données dans phpMyAdmin.
- Configurer la connexion à la base de données.
- Lancer le projet avec MAMP.
